Open items (defaults chosen — confirm at a gate, not blocking)

  • Hosting topology: default = shared BWH VPS, resource-limited + separate DB volume + nightly backup. Alternative = a second cheap node to isolate the DB from prod 9relay.
  • STT host/cost: default = 9relay-routed Whisper; revisit self-hosted faster-whisper if per-minute cost is high.
  • 9relay for app AI: default = yes (touches your prod key surface; usage will show under a dedicated key).
  • Web framework: default = Next.js App Router; lighter SPA possible since most surfaces are behind auth.
  • iOS offline depth: read-only offline (browse scenarios + review expressions); practice/scoring requires network (server-side AI).
