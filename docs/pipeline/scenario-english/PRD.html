AI Scenario English Trainer

A practical, scenario-driven English trainer: pick a real-world situation, practice by translation, role-play dialogue, or topic description, get focused AI corrections and a CEFR-aligned score, and grow a personal expression bank that feeds spaced review. Delivered as a shared backend service with both a web client and a native iOS client.

1Product Summary

This is not a traditional course app and not a generic AI chatbot. It is an AI scenario-based English trainer focused on helping users express themselves in real situations.

One-line positioning: Practice English through real-world scenarios, get focused AI corrections, and build a personal expression bank plus a CEFR ability profile.

Core value propositions

Practical

Common real-life situations: ordering, travel, small talk, workplace, interviews, topic description.

Corrective

AI surfaces grammar, vocabulary, naturalness, pronunciation, fluency, and task-completion issues — only the few that matter most.

Adaptive

The question bank evolves via AI generation, editorial review, behavior data, and mistake-based personal review.

Keywords

Scenario-based learningAI role-playTranslation practice Topic descriptionReal-time scoringCEFR estimate Expression bankDynamic question bankMistake-based review

2Background & Opportunity

Most AI English tools focus on tutors, pronunciation, vocab memorization, or gamified lessons. They reduce the speaking-practice gap but leave real holes.

Pain pointSymptomOur opportunity
Generic AI chat isn't practicalUsers don't know what to say; the chat ends with no clear outcome.Concrete scenarios with goals, roles, and target phrases drive practice.
Corrections aren't focusedToo many issues at once overwhelm the learner.Level-aware feedback; highlight only 1–3 key issues.
Output isn't retainedUseful expressions are forgotten by the next day.Auto-save vocabulary, patterns, and mistakes into a personal bank.
Progress is invisibleUsers don't know what's between them and the next level.Explainable scoring + CEFR ability profile with weak-point detail.
Static banks go staleFixed content is quickly exhausted or boring.Hybrid: curated base bank + AI-generated bank + personal review bank.
Opportunity: Not another generic tutor — a practical scenario-driven system with AI correction, ability tracking, expression review, and an evolving question bank.

3Goals & Non-goals

Goals

  • Help users express themselves in real-world English scenarios.
  • Improve naturalness via focused AI correction.
  • Auto-save unknown words, useful patterns, and recurring mistakes.
  • Provide a CEFR ability profile showing long-term progress.
  • Close the loop: practice → feedback → save → review → practice.
  • An expandable question bank with low content-maintenance cost.
  • Ship a shared backend with web and iOS clients in sync.

Non-goals (this version)

  • No full exam-prep question bank.
  • No community, rankings, or social features.
  • No live human teachers.
  • No official CEFR certification — AI estimate only.
  • English only; no other learning languages.
  • No scraping of competitor content, textbooks, or official exam questions.
  • No Android client this version.

6Practice Modes

ModeUser actionAI behaviorFocus
Scenario TranslationTranslate a Chinese prompt into natural English (or explain an English sentence).Returns corrected + more-natural version + error explanations.Vocab, patterns, natural phrasing.
Scenario DialogueRole-play with the AI in a real situation.Plays waiter / receptionist / interviewer / friend / colleague.Interaction, quick response, fluency.
Topic DescriptionSpeak 30s–2min on a topic.Evaluates structure, fluency, grammar, vocab, naturalness.Long-form speaking, coherence.

Example — Scenario Translation

Scenario: Ordering at a coffee shop
Prompt (user): I want an iced Americano, no sugar, can less ice?

AI feedback — more natural:
  I'd like an iced Americano with no sugar. Could you make it with less ice?
Explanation:
  1. "I'd like..." is more polite than "I want..." when ordering.
  2. "can less ice" is incomplete → "Could you make it with less ice?"
  3. "with no sugar" sounds more complete than "no sugar."
Save candidates: I'd like... · with no sugar · Could you make it with less ice?

10Scoring & CEFR

Scoring is a core differentiator — not one subjective AI number, but explainable dimensions tracked over time.

Compliance copy (required, verbatim where shown): "Your current CEFR level is an AI estimate for learning reference only. It is not an official language test score or certification."

Two layers

LayerDescriptionDisplay
Session scoreOne translation/dialogue/description task.Score 78/100 · Est. CEFR B1-
Long-term abilityRecent sessions → stable profile.Current A2+ · Stable A2–B1

Six dimensions

DimensionMeasures
Vocabulary RangeVariety/appropriateness of vocabulary & expressions.
Grammar AccuracyTense, articles, agreement, completeness.
FluencyRate, pauses, repetitions, self-corrections (speech).
CoherenceConnectors, consistency, logical flow.
InteractionResponding, clarifying, confirming (dialogue).
PronunciationPhonemes, stress, intonation, intelligibility (speech).

Technical flow

User speech → STT transcription
→ speech features (rate, pauses, repetitions, clarity, ASR confidence)
→ LLM rubric scoring (grammar, vocab, naturalness, interaction, task completion)
→ aggregation (session score, dimension scores, CEFR estimate)
→ report (summary, weak points, recommended review, next task)
ASR confidence gate: low-confidence audio is flagged, the user is asked to retry, and low-confidence results are excluded from long-term ability scoring.

11AI Feedback Strategy

Never dump every issue. Feedback is level-aware and mode-aware.

ModeDescriptionUsed in
Light correctionFlag only key issues without breaking flow.Dialogue
Instant correctionCorrect each sentence right after it.Translation
Post-session reviewAnalyze whole performance at the end.Topic description, long dialogues

Level-aware

A1–A2

Only correct errors that block understanding; short, copyable sentences.

B1–B2

Grammar, collocations, naturalness; native-like alternatives.

C1+

Tone, precision, style, logical structure.

Feedback payload (JSON contract)

{
  "original": "I want check in early.",
  "corrected": "I'd like to check in early.",
  "natural_version": "Would it be possible to check in early?",
  "issues": [
    {"type":"grammar","explanation":"'want' needs 'to do'; 'I'd like' is more polite in hotels."},
    {"type":"naturalness","explanation":"'Would it be possible to...' is a more polite request."}
  ],
  "save_candidates": ["I'd like to...", "Would it be possible to...?", "check in early"]
}

12Personal Expression Bank

The retention engine — not a vocab list, but a personal asset generated from real practice.

Vocabulary

Words the user doesn't know or misuses.

Sentence patterns

Reusable patterns like "Would it be possible to...".

Mistake pairs

Original → corrected → natural.

Saved expressions

Manually saved by the user.

Scenario phrases

Expressions tied to a scenario.

Review tasks

Generated from weak points + spaced repetition.

Mistake → review generation

Mistake: "I want check in early."
Corrected: "I'd like to check in early." / "Would it be possible to check in early?"
Generated review tasks:
  1. Use "I'd like to..." to say: "I want to check in early."
  2. Use "Would it be possible to..." to ask politely about early check-in.
  3. Re-enter the hotel front-desk scenario and use "check in early" naturally.

Surfaces (AI-native — two pages, not a menu)

Design principle: the app decides what to study; the user just shows up and practices. The whole learning loop collapses into ONE adaptive session feed. The scenario library, 3 practice modes, scoring, expression bank, and review still all exist — they are engine, not pages. Same features as the P0+P1 list above; far fewer screens.
Learner app (web + iOS) — THREE surfaces:

  STUDY  (the app, really)
    A single AI-driven session feed. On open, the coach hands the user the next
    best item — a scenario to practice, a sentence to translate, a dialogue turn,
    or a resurfaced weak point. The user responds (voice or text); correction,
    score, and "save to your bank" all happen INLINE; then it rolls into the next
    item. Adaptive next-item (no menu, no mode picker, no library browse).

  YOU  (the mirror)
    Long-term CEFR profile + dimension trends, the expression bank
    (vocab / patterns / mistakes / saved / scenario phrases), and review status.
    Reflect-and-look-back surface; everything active lives in Study.

  SETTINGS  (configure)
    Account + magic-link upgrade / sign out; voice & TTS preference; native
    language (for translation prompts); review reminders; appearance; data &
    privacy; about + the CEFR compliance copy. (AI runs server-side via 9relay,
    so no user API key here.)

  (Onboarding is a transient flow — anonymous start + optional magic-link upgrade —
   not a standing page.)

Operator (web only, OUTSIDE the learner app):
  Admin — question-bank items, lifecycle states, quality metrics, review/approve/archive

14Platform & Architecture (intent — detailed in TECH doc)

This is the PRD-level intent. The exact stack, schema, and APIs are decided in the Infrastructure Design / Tech Document (Step 4) by the Backend & Frontend workers and reviewed by the Coordinator.

Backend service

Owns data + business logic + AI orchestration. Exposes a REST/JSON API consumed identically by web and iOS. Server-side AI calls (can route via existing 9relay/LiteLLM gateway).

Web client

Responsive learner app + operator admin. Voice capture in-browser; thin, talks only to the API.

iOS client

Native SwiftUI app refactored from the existing repo. Reuses TTS/Speech plumbing; switches from local-only SwiftData to API-backed data (with sensible offline caching).

Shared contract: All AI outputs are structured JSON (feedback, scoring, generation). Every session is traceable to scenario_id, item_id, session_id. The API contract is the single source of truth both clients build against.

16Metrics & Acceptance

Product metrics (targets)

MetricDefinitionTarget
Practice completionComplete a session after starting.> 60%
Day-1 retentionReturn the next day.> 25%
Expression save rateSessions saving ≥1 expression.> 70%
Review conversionComplete a shown review task.> 35%
Scoring satisfactionUser rating of scoring usefulness.> 4.0/5
Complaint rateItems reported bad.< 2%

Functional acceptance criteria

  • User selects a scenario and completes ≥1 practice mode (web and iOS).
  • Speech is transcribed and passed into the AI feedback flow.
  • Every session produces a score report (total + CEFR + ≥4 dimensions).
  • AI feedback includes original, corrected, natural version, and explanation.
  • ≥1 save candidate extracted from each meaningful session.
  • Expression bank supports view, review, and mastery status.
  • Question items include source, license, status, version, quality metrics.
  • Low-quality items can be moved to review/archived via admin.
  • CEFR is labeled an AI estimate everywhere it appears.
