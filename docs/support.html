FAQ

常见问题

How do I get started?

如何开始使用？

Open the app, tap the "Me" tab in the bottom-right corner, then tap the gear icon in the top-right to open Settings. Choose an AI provider and enter your API key to begin.

打开应用后，点击右下角「Me」标签页，再点击右上角齿轮图标进入设置。选择一个 AI 服务商并输入 API 密钥即可开始。

Which AI providers are supported?

支持哪些 AI 服务商？

  • OpenAI (gpt-4o-mini)
  • Claude / Anthropic (claude-sonnet-4-6)
  • Kimi / Moonshot AI (moonshot-v1-8k)
  • DeepSeek (deepseek-chat)
  • Gemini / Google (gemini-2.5-flash)

Which text-to-speech services are supported?

语音合成支持哪些服务？

  • System Voice (no configuration required)
  • OpenAI TTS
  • ByteDance Volcengine TTS 2.0 — supports Dacey, Stokie, and Tim English voices
  • 系统语音（无需配置）
  • OpenAI TTS
  • 火山引擎 TTS 2.0（字节跳动）— 支持 Dacey、Stokie、Tim 三种英文语音

Where is my data stored?

数据存储在哪里？

All data is stored locally on your device and is never uploaded to any server. AI requests are sent directly to the provider you choose.

所有数据均存储在您的设备本地，不会上传到任何服务器。AI 请求直接发送至您选择的服务商。

How do I back up my settings?

如何备份设置？

In Settings, scroll to the bottom and tap "Export Config". Select "Backup" mode to export an .elc file containing all your configuration.

在设置页面底部，点击「Export Config」选择「Backup」模式即可导出包含所有配置的 .elc 文件。
